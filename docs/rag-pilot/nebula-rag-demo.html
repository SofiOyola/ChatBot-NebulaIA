Material original de demostración del flujo RAG

Este texto fue creado por el equipo del proyecto NébulaIA únicamente para comprobar de forma controlada la extracción, fragmentación, indexación, revisión y recuperación de un documento de demostración.

Límites del contenido

Este material no es un reglamento, una política institucional, una fuente curricular ni una comunicación oficial de una universidad. No contiene asignaturas, créditos, prerrequisitos, calificaciones, requisitos de matrícula ni datos personales. No debe emplearse para responder preguntas normativas, curriculares o individuales.

Flujo demostrativo

El flujo técnico separa la preparación del documento, la generación de representaciones vectoriales y la revisión humana. Un documento permanece identificado como material de demostración y su clasificación no cambia por el hecho de ser fragmentado o indexado.

Trazabilidad

Una prueba válida conserva el título, la entidad responsable, la fecha, el hash del contenido, la referencia de autorización y los localizadores de los fragmentos. Si falta evidencia o la clasificación es ambigua, el documento debe rechazarse.
